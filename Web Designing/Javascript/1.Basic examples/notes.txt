Token: Smallest unit of information.
------------------------------------------
Token includes :
1.Constant 

2.Variable
3.Keyword
4.Identifier
5.Seperator
6.Operator


Constant : Constant is the entity whose value connot be changed.
Here in Javascript we define constant by const keyword.

Variable: Variable is the name given to a memory location,whose value may change the execution of program.
we can define the execution of program.

keywords: keywords are reserved word,whose  meaning is already defined .We cannot use keyword as a variable name.

Identifier : User defined names
constant : uppercase
variable : lowercase
function:CamelCase--------------->addProduct(),addProductCategory()etc.

Seperator :  ,{}()[]
